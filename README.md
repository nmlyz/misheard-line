misheard-line writes one line to a text file: the apology a smart speaker gives its owner after mishearing "order pizza" as "order a visa". The line was picked from 39 candidates by pairwise judging against the brief — a mishearing with a life-sized consequence, closed on a perfectly timed undercut. The speaker reports the mistake the way a device would: plainly, in order, and one beat too late.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run. The line is 106 characters, a single line, and ends on its strongest beat. The program holds the line as one constant and checks it against the entry gate (length, single line, no leading or trailing space, exact judged length) before writing it, then reads the file back to confirm the bytes match.
